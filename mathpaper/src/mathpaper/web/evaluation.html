Current configuration

Passages
Page-contained, label-aware; 220-token budget, 24-token overlap when splitting
Embedding
all-MiniLM-L6-v2 · 384 dimensions
Fusion & reranking
BM25 + cosine search · RRF 60 · ms-marco-MiniLM-L6-v2 cross-encoder
Agent search
20 candidates · 5 passages · INT8 ONNX
Research tools
Passage search, statement lookup, and context expansion through MCP
Answer checks
Retrieved source IDs only, followed by a separate model support check; the checker can make mistakes

What to measure next

  1. Unseen questions. Build a separate test set with theorem comparisons, proof dependencies, and unanswerable questions.
  2. Complete evidence. Label relevant passages and check whether all required assumptions are available.
  3. Answer support. Review mathematical correctness and citation entailment independently of the generating model.
  4. Further ablations. Compare chunk sizes, retained passage counts, and agent tools on the separate set.

Current statistics support a development comparison. They do not estimate held-out answer accuracy, hallucination rates, or production latency percentiles.
